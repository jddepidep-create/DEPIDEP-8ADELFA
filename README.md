# Hypotenuse Distance Calculator

## Description
The Hypotenuse Distance Calculator is a simple program that solves for the length of the hypotenuse. The program solves this by using the Pythagorean Theorem, which calculates the longest side of a right triangle (hypotenuse).

## How to Run
1. Download the `Depidep_JohnOwen_hypotenuse.py` file.
2. Open the file in an IDE of your choice (such as VS Code, PyCharm, or IDLE).
3. Click the "Run" button (usually represented by a play icon).
4. Enter your values for side a and side b when prompted in the terminal window to see the calculated hypotenuse.

## Input Needed
You will need to input the 2 shorter sides of the right triangle. They are labeled as `side_a` and `side_b` in the program.

## Sample Output
```text
Enter the length of side a: 8
Enter the length of side b: 9

The hypotenuse is: 12.04
```
