# Project Title
Hypotenuse Distance Calculator
## Description
Briefly explain what the program does.
The Hypotenuse Distance Calculator is a simple program that solves for the length of the hypotenuse.
The program solves this by using the Pythagorean Theorem, which calculates the longest side of a right triangle (hypotenuse)
## How to Run
First, Download the "Depidep_JohnOwen_hypotenuse.py" file, 
Secondly, open it (i expect you to know how to open files) and select a IDE of your choice, 
Thirdly, Once the program pops up on your screen, click the "Run" button, most represented by a play button. 
Finally, once the execution window opens, type out your values for side a and side b, and the program will output the hypotenuse.
## Input Needed
List the values that the user needs to enter.
You will need to input the 2, other shorter sides of the right triangle. They are labeled as "side_a" and "side_b" in the program.
## Sample Output
- `Enter the length of side a: 8`
- `Enter the length of side b: 9`
- `The hypotenuse is: 12.04`

- `Process finished with exit code 0`
